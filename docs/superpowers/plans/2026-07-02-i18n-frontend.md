# i18n Frontend (Sub-project 1) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the React UI bilingual (French + English) via a dependency-free i18n module + a language toggle, converting every user-facing string.

**Architecture:** A small `web/src/i18n/` module (nested `fr`/`en` catalogs sharing a compile-checked `Messages` type; a `LanguageProvider` mirroring `ThemeProvider` with `navigator.language` auto-detect + localStorage persistence; a `t(key, vars?)` hook with `{var}` interpolation, `_one`/`_other` plurals, and an active→fr→key fallback). A TopBar FR/EN toggle, locale-aware date helpers, and an area-by-area string sweep. Backend/email i18n are separate later sub-projects.

**Tech Stack:** React 19, TypeScript, react-router, vitest + @testing-library/react, in `web/`.

## Global Constraints

- All work under `web/`; verify with `pnpm exec vitest run --exclude 'e2e/**' --no-file-parallelism` + `pnpm exec tsc --noEmit` (+ `pnpm build` at the end).
- **Lightweight custom** i18n — NO new runtime dependency.
- Catalogs: `web/src/i18n/fr.ts` (the source-of-truth shape) + `web/src/i18n/en.ts` typed `export const en: Messages` where `type Messages = typeof fr` — a missing/misnamed English key MUST be a `tsc` error. Every task that adds `fr` keys adds the matching `en` keys in the SAME task.
- Locale: `'fr' | 'en'`. Persistence mirrors `ThemeProvider` — `localStorage['lang']` + `document.documentElement.setAttribute('lang', …)`. First-visit default = auto-detect from `navigator.language` (`en*`→`en`, else `fr`).
- `t(key)` fallback chain: active-lang → French → the key string (dev `console.warn` on miss). `{var}` interpolation; `_one`/`_other` selected by a `count`/`n` var.
- French copy must be preserved EXACTLY as it currently reads when moved into `fr.ts` (no rewording). English is a faithful translation.
- "Converted" = the component renders via `t(...)`; "area complete" = no hardcoded user-facing French string literals remain in that area's `.tsx` (tests excluded).

`web/src/i18n/t.ts`:
```ts
import { fr } from './fr'
import { en } from './en'
import type { Messages } from './fr'

export type Lang = 'fr' | 'en'
const catalogs: Record<Lang, Messages> = { fr, en }

function lookup(cat: Messages, key: string): string | undefined {
  return key.split('.').reduce<unknown>((o, k) => (o && typeof o === 'object' ? (o as Record<string, unknown>)[k] : undefined), cat) as string | undefined
}

export function translate(lang: Lang, key: string, vars?: Record<string, string | number>): string {
  // plural: if a `count`/`n` var is present and `${key}_one|_other` exist, pick by it
  const n = vars?.n ?? vars?.count
  let raw: string | undefined
  if (typeof n === 'number') {
    const suffix = n === 1 ? '_one' : '_other'
    raw = lookup(catalogs[lang], key + suffix) ?? lookup(fr, key + suffix)
  }
  raw = raw ?? lookup(catalogs[lang], key) ?? lookup(fr, key)
  if (raw === undefined) {
    if (import.meta.env?.DEV) console.warn(`[i18n] missing key: ${key}`)
    return key
  }
  return vars ? raw.replace(/\{(\w+)\}/g, (_, k) => String(vars[k] ?? `{${k}}`)) : raw
}
```
`web/src/i18n/LanguageProvider.tsx` (mirror `ThemeProvider`):
```tsx
import { createContext, useContext, useEffect, useMemo, useState, type ReactNode } from 'react'
import { translate, type Lang } from './t'

function detect(): Lang {
  const s = localStorage.getItem('lang')
  if (s === 'fr' || s === 'en') return s
  return navigator.language?.toLowerCase().startsWith('en') ? 'en' : 'fr'
}

type TFunc = (key: string, vars?: Record<string, string | number>) => string
const Ctx = createContext<{ lang: Lang; setLang: (l: Lang) => void; t: TFunc }>({ lang: 'fr', setLang: () => {}, t: (k) => k })

export function LanguageProvider({ children }: { children: ReactNode }) {
  const [lang, setLang] = useState<Lang>(detect)
  useEffect(() => {
    document.documentElement.setAttribute('lang', lang)
    localStorage.setItem('lang', lang)
  }, [lang])
  const t = useMemo<TFunc>(() => (key, vars) => translate(lang, key, vars), [lang])
  return <Ctx.Provider value={{ lang, setLang, t }}>{children}</Ctx.Provider>
}

export const useLang = () => { const { lang, setLang } = useContext(Ctx); return { lang, setLang } }
export const useT = () => useContext(Ctx).t
```
